# Название проекта: Анализ пользовательского поведения
## Описание
Анализ повторных покупок пользователей и интервалов между заказами.

## Результаты
1. Пользователи с 5+ заказами возвращаются в 2 раза чаще
2. Средний интервал: 9.9 дней vs 21.3 дня
